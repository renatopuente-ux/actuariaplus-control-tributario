# actuariaplus-control-tributario
Prototipo de rediseno UX/UI del Control Tributario de Provisiones (CTP) - modulo de Actuaria+

## Vista hermana · el analista en ActuaFast

Este prototipo es la vista del **cliente** (lo que consume en Actuaria+). El recorrido de
**ejecución interna** — cómo el analista de Operaciones ejecuta, valida y libera el CTP —
tiene su propia maqueta en ActuaFast:

- https://renatopuente-ux.github.io/actuafast-ctp-analista/

La liberación en su pantalla P5 ("Finalizar y liberar a Actuaria+") es lo que publica el
resultado que esta vista muestra.
